# ☕ 카페 마케팅 대시보드

## 한 줄 소개

> **가게 사장님을 도와주는 AI 비서예요.**
> 매일 번 돈을 적고, 우리 동네 손님을 살펴보고, 옆 가게랑 비교하고,
> "이번 주말엔 뭘 하면 좋을까?" 를 AI에게 물어볼 수 있어요.

## 누가 쓰나요?

카페나 음식점처럼 **작은 가게를 하는 사장님** 이 써요.

### 1️⃣ 가입하고 로그인하기

![로그인 화면](docs/images/01-login.png)

**이 화면은 뭐예요?**
앱에 들어가는 문이에요. 처음이면 **회원가입**, 다음부터는 **로그인** 하면 돼요.

**이렇게 하세요**
1. `회원가입` 을 눌러 아이디와 비밀번호를 만들어요.
2. 다시 돌아와서 로그인해요.
3. 한 번 로그인하면 한동안 자동으로 로그인 상태가 유지돼요.

---

### 2️⃣ 내 가게 등록하기 (사업자 인증)

![사업자 인증 화면](docs/images/02-biz-auth.png)

**이 화면은 뭐예요?**
"이 가게가 진짜 내 가게예요" 라고 확인받는 곳이에요.
**처음 가입해서 아직 가게를 연결하지 않은 사람에게만 보여요.** 이미 인증·연결을 끝낸 사람은 로그인하면 바로 홈으로 가요. (다시 관리하려면 `/biz-auth?manage=1`)

**이렇게 하세요**
1. **사업자등록번호** 를 입력해요.
2. 확인 버튼을 누르면 국세청에 진짜 사업자인지 물어봐요.
3. 통과하면 목록에서 **내 가게를 골라 연결** 해요.
4. 연결이 끝나면 이제 장부·상권·비교 기능을 모두 쓸 수 있어요.

### 3️⃣ 홈 화면 — 오늘 장사 한눈에 보기

![홈 대시보드](docs/images/03-home.png)

**이 화면은 뭐예요?**
앱을 열면 처음 보이는 요약 화면이에요.
이번 달 매출이 잘 나오고 있는지, 지난달보다 빠른지 느린지를 보여줘요.

### 4️⃣ 장부 — 번 돈과 쓴 돈 적기

![장부 화면](docs/images/04-ledger.png)

**이 화면은 뭐예요?**
용돈 기입장처럼, 가게가 **번 돈(매출)** 과 **쓴 돈(지출)** 을 적는 곳이에요.

**이렇게 하세요**
1. **매출 넣기**
   - 하루 매출을 직접 숫자로 입력하거나,
   - 카드사에서 받은 **매출 리포트 엑셀 파일을 그냥 올리면** 앱이 알아서 읽어요.
2. **지출 넣기** — 재료비, 월세, 인건비 같은 걸 카테고리별로 적어요.
3. **고정비 등록** — 매달 똑같이 나가는 돈(월세 등)은 한 번만 적어두면 돼요.

**여기서 볼 수 있는 것**
- 이번 달 **매출 − 지출 = 순이익** (흑자면 빨강, 적자면 파랑으로 표시)
- 지출이 어디에 많이 나갔는지 **도넛 그래프**
- **월별 비교** — 지난 몇 달과 비교

---

### 5️⃣ 상권 분석 — 우리 동네 손님 알아보기

![상권 분석 화면](docs/images/05-market.png)

**이 화면은 뭐예요?**
우리 가게 **주변 동네(상권)** 에 어떤 손님이 오는지 알려주는 화면이에요.

**여기서 볼 수 있는 것**
- **5분기 매출 추이** — 우리 상권 / 자치구 / 서울시를 선으로 비교
- **요일별 매출 순위** — 무슨 요일에 장사가 잘 되는지 (1등, 2등, 3등…)
- **시간대별 매출** — 몇 시에 손님이 가장 많은지
- **성별 매출 비중** — 여자 손님이 많은지 남자 손님이 많은지
- **연령대별 매출** — 20대·30대·40대 중 누가 제일 많이 쓰는지 (도넛)
- **임대 시세·소득 수준**, **주변 시설**(관공서·병원·학교·교통시설 개수)

---

### 6️⃣ 경쟁사 비교 — 옆 가게랑 비교하기

![경쟁사 비교 화면](docs/images/06-compare.png)

**이 화면은 뭐예요?**
내 가게와 **주변 경쟁 가게(최대 3곳)** 를 나란히 비교해요.

**이렇게 하세요**
1. 비교하고 싶은 가게를 **최대 3개** 체크해요.
2. **`비교하기`** 버튼을 딱 한 번 누르면,
   비교 결과 + **AI 리뷰 분석** 이 한꺼번에 나와요. *(최대 30초 정도 걸려요)*

**여기서 볼 수 있는 것**
- **강점 키워드 거미줄 그래프** — 어떤 점이 강한지 가게별 비교
- **AI 리뷰 분석** — 좋은 말 / 나쁜 말 비율, 놓치기 쉬운 개선 힌트
- **AI 강·약점 비교** — "이 가게는 뭐가 강하고, 우리랑 뭐가 다른지" 를 문장으로 설명
- **지도** — 경쟁 가게들이 어디 있는지
- 동네 카페 평균과 비교한 **우리 가게 리뷰 수 순위**

---

### 7️⃣ AI 마케팅 챗봇 — AI에게 물어보기

![마케팅 챗봇 화면](docs/images/07-marketing-chat.png)

**이 화면은 뭐예요?**
우리 가게 정보(메뉴·리뷰·동네 특징)를 이미 알고 있는 **AI 상담원** 이에요.

**이렇게 하세요**
- 그냥 채팅하듯이 물어보면 돼요.
  - "이번 주말 이벤트 아이디어 알려줘"
  - "우리 가게 리뷰에서 자주 나오는 불만이 뭐야?"
  - "20대 손님을 더 오게 하려면 어떻게 해?"
- AI가 **우리 가게 데이터에 맞춰** 대답해 줘요.

### 구성 요소

| 부분 | 내용 |
| --- | --- |
| 웹 앱 (`cafe-dashboard/`) | **Java 21 + Spring Boot 4.1.0** (Spring MVC, Spring Data JPA, Spring Security, Validation), 화면은 **Thymeleaf** 서버 렌더링 |
| 데이터베이스 | **PostgreSQL** (Supabase, session pooler), HikariCP, `spring.jpa.hibernate.ddl-auto=none` |
| 차트 | 인라인 SVG 직접 구현(도넛·레이더·라인) + Chart.js 4(CDN) |
| 엑셀 파싱 | Apache POI (매출 리포트 업로드) |
| 외부 API | **OpenAI** `gpt-4o-mini` (챗봇 · 리뷰 인사이트), **국세청 사업자등록정보 진위확인**(공공데이터포털), **Kakao Maps** JS SDK |
| 데이터 수집 (`Web crawling/`, `Database/`) | **Python + Scrapling**(stealth 헤드리스)로 네이버 지도 크롤링 → 매장별 Excel → `Database/load_data.py` 로 Postgres 적재 |
| 스키마 | `Database/create_tables_postgres.sql` (테이블 20개) — 앱이 아니라 이 파일이 소유 |
| 자동 갱신 | `CrawlRefreshService` `@Scheduled(cron = "0 0 22 * * *")` — 매일 22:00 크롤링 리프레시 |

### 로컬 실행

```powershell
# 1) 스키마 1회 적용: Database/create_tables_postgres.sql
# 2) 데이터 적재
pip install -r crawler-requirements.txt
python Database/load_data.py
# 3) 앱 실행 (Database/.env 를 읽어 환경변수로 주입)
cd cafe-dashboard
./run-dev.ps1        # → http://localhost:8080
```
